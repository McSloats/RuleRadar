GitHub API Token Required

A personal access token must be configured before you can use RuleRadar.

{# ── Why ─────────────────────────────────────────────────────────────────── #}
Why is this required? Without a token, GitHub's public API is limited to 60 requests/hour. RuleRadar needs to index thousands of rule files across two repositories, which requires the authenticated limit of 5,000 requests/hour. Your token is only used to read public repository data — it never modifies anything.
{# ── How to get a token ──────────────────────────────────────────────────── #}

How to create a GitHub personal access token:

Classic token (simplest)

  1. Go to github.com/settings/tokens/new
  2. Set a descriptive Note — e.g. RuleRadar
  3. Set an Expiration (90 days or longer recommended)
  4. Under Select scopes, tick public_repo
  5. Scroll down and click Generate token
  6. Copy the token — it starts with ghp_

Fine-grained token (more restrictive)

  1. Go to github.com/settings/personal-access-tokens/new
  2. Set a Token name and expiration
  3. Under Repository access → Only select repositories → add SigmaHQ/sigma and splunk/security_content
  4. Under Permissions → Repository permissions → Contents: Read-only
  5. Click Generate token
  6. Copy the token — it starts with github_pat_
